### 新踩到的坑（易复发）

1. **Vite 8 用 rolldown，`manualChunks` 只接受函数**：对象写法直接构建失败，两个 Node 版本同时报错。
2. **平台文件只放平台实现**：`add()` 曾写在带 `//go:build linux` 的文件里，导致 Windows 构建 `undefined: add`。
3. **重构后必须立即 `go build ./...`**：`internal/task/pool.go` 的 `package collect` 漏改，报 `imported as collect and not used`。
4. **沙箱 safe-delete 拦截批量删除**：脚本里 `rmtree(node_modules/dist)`（2525 文件 > 阈值 50）抛
   `SAFE_DELETE_BULK_CONFIRM_REQUIRED`；构建脚本不要自己删 outDir，交给 `vite build --emptyOutDir`。
5. **Go 模块代理**：`proxy.golang.org` 返回 Bad Gateway，必须 `GOPROXY=https://goproxy.cn,direct` + `GOSUMDB=off`。
6. **Windows 下跑 npm**：`npm` shell 包装器在损坏的 bash 里不可用，要用
   `node.exe <node>/node_modules/npm/bin/npm-cli.js`（工具：`D:\pj\.spikes\tools\npmrun.py`）。
