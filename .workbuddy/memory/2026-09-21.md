### 关键架构决策（后续会话直接沿用）

- **D13 存储载体**：元数据 → SQLite（`modernc.org/sqlite`，**必须免 CGO** 否则无法静态编译）；时序 → `prometheus/prometheus/tsdb` 作为**库**嵌入进程（无独立进程/端口/容器）。
- **D14 零外部依赖**：不依赖容器运行时、外部数据库、目标机已装工具；不引入 `install_dep_apps`；Agent 自带 `smartctl`；IPMI 优先纯 Go 库、`ipmitool` 只作兜底。收益：常驻内存 1.5–2GB → 120–250MB。
- **D15 进程自管**：`cmd/main` 用 PID 文件 + `TERM→KILL`，`status` 必须返回 0/3；失败前写 `TRIM_TEMP_LOGFILE`；`start` 必须幂等；补 `/healthz` 就绪探测（curl→wget→进程存活三级降级，飞牛上未必有 curl）。
- **D16**：包内含原生二进制 → `platform=x86`（**不能再用 all**），ARM 需另出 `platform=arm` 包，CI 做构建矩阵；`check_fpk.py` 已加断言。
- **D17**：前端 `go:embed` 进二进制，`app/ui` 只保留桌面入口配置与图标。
- 失效：D6（compose 资源配额）、D7（MySQL/SQLite 二选一）→ 由 D13/D14 取代；D1 结论保留、实现方式改为进程直写。
- SQLite 侧改进：用**部分唯一索引**（`WHERE state='firing'`）替代 MySQL 时代的 `active_key` 置 NULL 技巧；`STRICT` 表；`auto_vacuum=INCREMENTAL` + 定期 `incremental_vacuum` 才有空间回收。
