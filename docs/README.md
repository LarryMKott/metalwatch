# MetalWatch 文档中心

> 面向多机房、跨网段物理服务器集群的**硬件级监控、遥测与管控平台**。
> 部署载体为飞牛 OS 原生应用（FPK），Agent 覆盖 Linux / Windows，
> 支持**带内 Agent + 带外 IPMI** 双采集模式。
