# 04 接口契约

三组接口，鉴权方式互不通用：

| 组 | 前缀 | 鉴权 | 调用方 |
| --- | --- | --- | --- |
| Agent 上报 | `/api/v1/agent/*` | `Authorization: Bearer <agent_token>` | 跨平台 Agent |
| 管理接口 | `/api/v1/*` | 会话 Cookie / JWT（WebUI 内部） | WebUI |
| 开放接口 | `/api/v1/open/*` | `Authorization: Bearer <api_token>`（只读 scope） | 外部系统 |

另有 `/healthz`（存活探针，免鉴权）与 `/internal/metrics`（Prometheus 抓取，**仅容器网络可达**）。

---

## 一、通用约定

- 传输：HTTP/1.1 + TLS（证书使用飞牛证书管理配置，见 01 文档 D2/PRD §2.7.5）。
- 请求体：`application/json; charset=utf-8`，允许 `Content-Encoding: gzip`（上报体量 >32KB 时必须压缩）。
- 时间：一律 **RFC 3339 UTC** 字符串（`2026-09-21T14:19:33Z`），服务端按 `wizard_timezone` 展示。
- 错误体统一：
  ```json
  { "code": "enroll_code_used", "message": "注册码已被使用", "request_id": "0f3c…", "detail": {} }
  ```
- 频率限制：Agent 上报按 Token 限流（默认 2 次/秒/主机）；管理接口按账号限流。
- 分页：`?page=1&page_size=50`（上限 500），响应带 `{ "items": [], "total": 0, "page": 1, "page_size": 50 }`。

### 错误码表（节选）

| code | HTTP | 含义 |
| --- | --- | --- |
| `unauthorized` | 401 | 缺 Token / Token 无效 |
| `token_revoked` | 401 | Token 已吊销 |
| `token_expired` | 401 | Token 过期 |
| `enroll_code_used` | 401 | 注册码用尽 |
| `enroll_code_expired` | 401 | 注册码过期 |
| `forbidden_scope` | 403 | scope 不足（如只读 Token 写操作） |
| `host_not_found` | 404 | 主机不存在 |
| `payload_too_large` | 413 | 上报体超限（上限 8MB） |
| `timestamp_out_of_range` | 422 | 补传时间戳超出 24h 窗口 |
| `metric_not_allowed` | 422 | 指标名不在白名单内 |
| `rate_limited` | 429 | 触发限流 |
| `internal_error` | 500 | 服务端异常（含 `request_id` 便于排查） |

## 二、Agent 上报接口

### 2.1 注册

`POST /api/v1/agent/enroll`

```json
{
  "enroll_code": "MW-7F3K-9QX2-8LMD",
  "hostname": "node-042",
  "smbios_uuid": "4c4c4544-0044-3910-8032-b7c04f4a4d32",
  "primary_ip": "10.20.3.42",
  "os_type": "linux",
  "os_version": "Debian 12 (kernel 6.1.0-18-amd64)",
  "agent_version": "0.1.0",
  "collect": ["sensors", "smart", "raid", "net_err"]
}
```

响应 `201`：

```json
{
  "host_id": 142,
  "agent_token": "mwa_9c1f…",      // 仅此一次返回明文，Agent 需存到本地 0600 文件
  "report_interval_sec": 30,
  "asset_interval_sec": 86400,
  "report_url": "/api/v1/agent/report",
  "server_time": "2026-09-21T14:19:33Z"
}
```

- `smbios_uuid` 相同视为同一台机器 → 复用 `host_id`（重装 Agent 不产生重复资产）。
- 已存在主机且其 Token 未吊销：返回 `409 host_already_enrolled`，Agent 需带 `--force-reenroll` 才继续。

### 2.2 指标 + 硬件上报

`POST /api/v1/agent/report`

```json
{
  "batch_id": "b1f2c3d4-…",         // 幂等键，重放不重复入库
  "host_id": 142,
  "mode": "agent",
  "collected_at": "2026-09-21T14:19:30Z",
  "sequence": 88213,
  "metrics": [
    { "name": "cpu_temp_celsius",     "labels": { "chip": "Socket0" }, "value": 47.0 },
    { "name": "fan_rpm",              "labels": { "slot": "Fan1" },    "value": 4320 },
    { "name": "power_watts",          "labels": { "slot": "Total" },   "value": 218.5 }
  ],
  "smart": [
    {
      "device": "/dev/sda", "model": "ST8000NM000A", "serial": "ZR5XXXXX",
      "media_type": "HDD", "capacity_bytes": 8001563222016,
      "temp_celsius": 38, "status": "OK", "reallocated_sectors": 0, "power_on_hours": 21440
    }
  ],
  "raid": [
    { "controller": "PERC H730", "array": "vd0", "level": "RAID5",
      "state": "Optimal", "rebuild_percent": 0, "disks": 4, "failed_disks": 0 }
  ],
  "inventory": {                      // 静态资产：仅当指纹变化时才带上，否则省略
    "fingerprint": "sha1:9a1b…",
    "cpu": [ { "slot": "Socket0", "name": "Intel Xeon Silver 4310", "cores": 12 } ],
    "memory": [ { "slot": "DIMM_A1", "name": "Samsung M393A4K40DB3", "size_bytes": 34359738368, "serial": "12AB34CD" } ],
    "disks": [ { "slot": "Disk0", "name": "ST8000NM000A", "serial": "ZR5XXXXX", "capacity_bytes": 8001563222016 } ],
    "nic": [ { "slot": "eth0", "name": "Intel X710", "mac": "3c:ec:ef:00:11:22" } ],
    "bios": { "version": "2.15.1", "date": "2025-06-01" },
    "mainboard": { "vendor": "Dell Inc.", "name": "0YWR8T" }
  }
}
```

响应 `202`：

```json
{ "accepted": 9, "rejected": 0, "next_report_at": "2026-09-21T14:20:00Z", "config_version": 7 }
```

- `host_id` 与 Token 绑定主机不一致 → `403 forbidden_scope`。
- `labels` 不接受高基数值（序列号、时间戳）；出现即 `422`。
- 补传：`collected_at` 允许回溯 24h；超出 → `422 timestamp_out_of_range`。
- 响应携带 `config_version`，与本地不一致时 Agent 调用 2.4 拉取新配置。

### 2.3 心跳

`POST /api/v1/agent/heartbeat`（轻量，无指标）

```json
{ "host_id": 142, "agent_version": "0.1.0", "uptime_sec": 183200, "config_version": 7 }
```

响应 `200`：`{ "ok": true, "config_version": 8, "report_interval_sec": 30 }`

### 2.4 拉取采集配置

`GET /api/v1/agent/config`（Bearer agent token）

```json
{
  "config_version": 8,
  "report_interval_sec": 30,
  "asset_interval_sec": 86400,
  "smart_interval_sec": 900,
  "collect": ["sensors", "smart", "raid", "net_err"],
  "spool": { "max_age_sec": 86400, "max_bytes": 52428800 },
  "upgrade": { "url": "", "version": "" }
}
```

### 2.5 采集异常上报（Agent → 服务端）

`POST /api/v1/agent/errors`

```json
{
  "host_id": 142,
  "errors": [
    { "component": "smart", "device": "/dev/sdb", "code": "tool_failed",
      "message": "smartctl exit 2: device not ready", "occurred_at": "2026-09-21T14:10:00Z" }
  ]
}
```

服务端行为：写 `collect_run(state=fail)`，**不**推导硬件结论；同一 `(component, device, code)` 15min 内只落一条。

**指标查询示例**

`GET /api/v1/hosts/142/metrics?metric=disk_temp_celsius&labels=device:/dev/sda&start=2026-09-20T00:00:00Z&end=2026-09-21T00:00:00Z&step=300`

```json
{
  "metric": "disk_temp_celsius",
  "step": 300,
  "series": [
    { "labels": { "device": "/dev/sda", "mode": "agent" },
      "points": [ [1758384000, 37.0], [1758384300, 38.0] ] }
  ],
  "unit": "celsius",
  "source": "prometheus",
  "downsampled": true
}
```

> 出图经服务端转发 `query_range`；`step` 由服务端按区间自动选择（≤24h→raw 30s，>24h→5m 聚合），并对越界点做 `null` 处理而不是丢点。

## 四、开放接口（只读 Token）

`GET /api/v1/open/hosts`、`/api/v1/open/hosts/{id}`、`/api/v1/open/hosts/{id}/metrics`、`/api/v1/open/alerts`

- 仅支持 `GET`；任何写操作返回 `403 forbidden_scope`。
- 不含 BMC 用户名/密码、不含审计日志。
- 响应字段与内部接口一致，便于外部系统（Grafana 之外的自建面板）复用。

## 五、出站告警 Webhook

`POST <通道 url>`，`Content-Type: application/json`，超时 10s，失败按 3 次指数退避重试（1s/5s/25s）。

```json
{
  "event": "alert.firing",
  "severity": "major",
  "alert": {
    "id": 90233,
    "category": "raid",
    "metric": "raid_state",
    "object": "vd0",
    "value": 1,
    "threshold": 1,
    "title": "RAID5 vd0 降级",
    "first_seen_at": "2026-09-21T14:10:00Z"
  },
  "host": { "id": 142, "hostname": "node-042", "primary_ip": "10.20.3.42",
            "sn": "CN1234567", "site": "北京-机房A", "rack": "R12", "geo_country": "CN" },
  "ts": "2026-09-21T14:10:05Z"
}
```

`event` 取值：`alert.firing` / `alert.resolved` / `alert.suppressed` / `agent.offline` / `agent.online` / `change.detected`。

- 请求头带 `X-MetalWatch-Event` 与 `X-MetalWatch-Signature`（HMAC-SHA256，密钥在通道配置中）。
- **绝对不包含** BMC 凭据、SMTP 凭据或系统内部路径。

## 六、Prometheus 抓取契约（内部）

`GET /internal/metrics`（仅容器网络可达；如经反向代理暴露，必须加内网限制）

- 文本格式 `text/plain; version=0.0.4`。
- 指标与标签严格遵循 `03-数据库设计.md` §2。
- 服务端按主机每 30s 输出一次最新值；无数据时输出 `metalwatch_up 0`。
- 该端点由服务端从内存缓冲生成，**不读 MySQL**，保证采集路径与数据库解耦。
