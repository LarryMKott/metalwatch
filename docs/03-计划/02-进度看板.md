## 6. 已知缺口与风险（必须记住）

| 级别 | 事项 |
| --- | --- |
| 🔴 阻断 | 管理接口**无鉴权**（W11 未完成），当前只能在内网使用 |
| 🔴 阻断 | 时序数据**没有落点**：指标上报后只更新在线状态，不入库（W1c） |
| 🔴 阻断 | Agent 仍是 HTTP/JSON，**未切到 gRPC**（W3 / W6） |
| 🟠 高 | Windows 采集依赖 C# NativeAOT 组件，本机无 .NET SDK，无法编译验证 |
| 🟠 高 | FPK **未上真机**：静态二进制能否运行、package 用户写权限、重装数据恢复三项均未验证 |
| 🟡 中 | 前端页面数据为兜底空态，未与后端联调 |
| 🟡 中 | `go test -race` 本机跑不了（无 gcc），只进了 CI |
