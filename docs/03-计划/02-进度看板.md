| 🟠 高 | Windows 采集依赖 C# NativeAOT 组件，本机无 .NET SDK，无法编译验证 |
| 🟠 高 | 初始管理员口令会打进启动日志并写入 `bootstrap_admin.txt`（0600）—— 部署后必须提醒用户改密并删除该文件 |
| 🟡 中 | 告警通知仅 Webhook 已接：邮件 / syslog 渠道未做（M6 的低优先项） |
| 🟡 中 | 会话无黑名单：登出只清客户端令牌，无法远程强制下线（单机场景接受） |
| 🟡 中 | 前端联调具备条件但未逐页验证：大盘 / 资产曲线 / 告警中心已有真实数据源（登录页为新增，未做浏览器实测） |
| 🟡 中 | TSDB rollup/清理由 5 分钟维护循环执行，长周期查询（>24h 聚合档）需运行一段时间后才有数据 |
